# Scritti FSA

Biblioteca digitale degli scritti della Beata Anna Rosa Gattorno e dei libri della Famiglia di Sant'Anna, in italiano, portoghese, spagnolo e inglese.

Scaffali: scritti, antologie, vita, figure, Famiglia, Movimento della Speranza (libri: «Cristo in voi», «Il cammino ecclesiale», «Alleanza»).

Si apre e si installa da: https://figlidisantanna.github.io/scritti-madre-rosa/

Istituto Figli di Sant'Anna
